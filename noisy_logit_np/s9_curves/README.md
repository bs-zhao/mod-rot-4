# 回归 NP 的 S9 / S9_2 旋转扫描：指标随角度、解析式 vs 神经网络、最小值点的角度

对 `noisy_logit_np` 里训练的 10 个回归 NP（C1、C2、C3、CR3、CR4 各一个原始 NP "nn1"，加各一个独立重训 NP "r2"）做与二元选择版 S9 / S9_2 **同样的构造**（相关代码拷贝，没有 import `nn/`）：

- **S9：** R* = 原始 Z（以 TRAIN 中心化）到 [TRAIN 标准化 T, 0] 的正交 Procrustes；U = R·Z。
- **S9_2：** 先对全体被试做逐轴 z-score 得 Zz，再同样拟合 R*，U = R·Zz。
- **扫描：** 前 d 个轴的每个子集（k=2..d）× 角度 0,15,…,90°，G = 相邻平面 Givens 旋转的有序乘积（每个都转该角度），R = G·R*；另有未扫描的基准 R*。
- **能量与指标：** 与 `metric_lab/03_s9_metric_curves` 完全相同的做法（4096 点，解析式用真 T、神经网络用 Z，同一批被试与 X；坐标 [潜变量原值, X 标准化]；logit 目标；对输入的完整自动微分 Hessian；152 个指标 + 候选 `CAND`）。回归 NP 的 logit 是 decoder 输出还原到 y 的单位。
- **库：** 10 个 NP × {S9, S9_2} = 20 个库。

文件：`s9_regression.py`（构造 + 计算，结果在 `results/raw/`）、`analyze_reg.py`（相关系数、曲线、散点、热力图）、`angles_reg.py`（最小值点角度与通过判定）、`core.py`、`metrics152.py`。输出：`results/correlations_long.csv`、`correlation_summary.csv`、`key_metrics_pearson.csv`、`argmin_long.csv`（每条扫描的最小值角度）、`argmin_summary.csv`、`angle_pass_summary.csv`、`figures/curves__*.png`（曲线）、`figures/scatter__*.png`、`figures/argmin_hist_{s9,s9_2}.png`（最小值点角度分布）。

## 3. 读法
1. **C 系列：** 解析式与神经网络的曲线几乎重合（r≥0.99），全局 / 按列的 UX 集中度指标的最小值都精确落在 R*（0/90°）。这与盲搜在 C1/C2/C3 上成功一致。
2. **CR 系列：** 全局类指标（UX.hoy、UXcol、POOL）与解析式相关仍然高（0.93–0.99），但**解析式本身**在 CR 上就不偏好 R*（CR4 的 UX.hoy 解析式最小值也不在 0/90°），所以神经网络照着学也不会偏好 R*。真正偏好 R* 的是 **rowsp / Fz.A+B+C 一族**：在 CR3 nn1 与 CR4 nn1 上，它们的最小值点 100% / 91% / 100% 在 0°，与盲搜用 rowsp 解决 CR4 的结论一致。
3. **候选 CAND 在 CR4 上最小值点偏离**（神经网络只有 25% 的扫描在 0°，而解析式是 100%），原因是 UXcol.hoy 部分在 CR4 上把最小值拉离 R*（该成分单独的最小值在 15–75°）。
4. **CR3 r2 比 nn1 差**（rowsp 0.82 / CAND 0.64），CR4 r2 是训练失败的 NP，所有指标都不行。
5. 不同来源的曲线用各自的 z 分数画在同一张图上，只比较形状。

## 限制
- 每个模型只有 2 个回归 NP；CR3 只有 915 个内点（边界点的 X 导数无经典定义）；CR4 r2 是失败的 NP。
- 0° 与 90° 在值上平局（带符号置换等价），报告为 0°；"最小值点"只取 15° 网格。
- 这是局部角度检验，不包含盲搜的全局搜索；与盲搜的对照见 `metric_lab/03_s9_metric_curves/README.md`。

## 更新：CR4 r2 用 β=5e-5 重训（取代上文所有 "CR4 r2" 的数字）
按"Z→T 线性回归各参数 R² 是进入下一步的硬门槛（C 系列 ≥0.7，CR 系列 ≥0.65）"的要求，原 CR4 r2（β=5e-4，最低 R² 0.131）不合格；用 β=5e-5 重训（其余配置与数据不变，训练 500 个 epoch，最佳第 457 个），旧版本备份在 `checkpoints/beta5e-4_backup/` 与 `results/beta5e-4_backup/`。新 CR4 r2：对真实 logit R² 0.997；Z→T 线性 R² = 0.901 / 0.838 / 0.904（过门槛）；监督上限 MCC 0.936（泄露 0.042 / 0.057）。注意：这一步用 T 只是判定 NP 合格，不用于选指标。
- 新 CR4 r2 的解析式–神经网络相关（S9 / S9_2）：UX.hoy 0.98，UXcol.a0.hoy 0.98 / 0.99，rowsp.a0.75 0.66 / 0.82，候选 0.52 / 0.69，Fz.A+B+C 0.73 / 0.82。
- 角度检验通过数（NN 完美 / 放宽）：CR4 nn1 8 / 9（S9）、6 / 7（S9_2）；CR4 r2 0 / 6（S9）、3 / 7（S9_2）。
- 重新计算的名单（所有库、神经网络）：C 系列完美 38、放宽 51；CR3 完美 0、放宽 14；**CR4（nn1 与 r2 都满足）完美 0、放宽 3：`rowsp.a0.75.q0.1`、`Fz.A+B+C`、`Fz.A+K+C`**。C 与 CR3 同时满足（放宽）：`CAND.rowsp.75+UXcol.hoy`、`SL0.UX.e0.03`；三者同时满足：0 个。
- CR4 的 rowsp.a0.75 在 nn1 上 100% 的扫描最小值在 0/90°，在 r2 上只有 25%（平均偏离 11°）；`Fz.A+B+C` 在 nn1 / r2 上是 100% / 75%。
