# noisy_logit_np：带噪声 logit 回归版 NP + 盲旋转测试（独立实验）

**与项目其余部分的区别：** 生成模型不再产生二元选择，而是产生**连续的带噪声 logit**；NP 的重构损失由交叉熵改为 **MSE**；其余（C1、C2、C3、CR3、CR4 的参数 T、刺激 X 与 logit 函数，NP 架构，Z 提取方式，旋转测试方法）保持不变。所有代码、数据、检查点、结果都在本文件夹内；对项目其余部分只**只读引用**五个生成模型的定义（`models/src`），不修改、不向其中写入。

## 1. 设定

- **目标变量：** `y = η(T, X) + ε`，`ε ~ N(0, s²)`，`s² = Var(η)·(1−R²)/R²`，`R² = 0.8`。即**完美预测器（知道真实 logit）能解释 y 的 80 % 方差，20 % 是不可约噪声**。`Var(η)` 取各模型全部试次的 logit 方差；实现的完美预测 R² 为 0.7998–0.8002。（"20 % 噪声 / 信噪比 80 %"在此解释为方差占比；若想改成噪声标准差占 20 %，改 `common.py` 里的 `R2_TARGET` 或 `gen_data.py` 的 `sd` 即可。）
- T、试次数、X 使用与原 S1 完全相同的随机流（每个被试的真参数和刺激与二元选择版相同），噪声单独用一个随机流。8000 被试。CR3 用已有的固定 500 题库（只读）。
- **NP：** 编码器 = Set Transformer（embed 32，2 个 SAB + PMA，4 头，summary 64，输入 `[x, y]`）→ 高斯潜变量；解码器 = `[x, z] → 128-256-128 (GELU) → 1`，输出预测的 logit。损失 `MSE + β·KL`，β = 5e-4，学习率 5e-4，batch 128，上下文比例 U[0.25, 0.80]（每次呈现重新抽样），被试 70/15/15 划分，验证损失早停（耐心 50，最多 500 epoch），GPU 训练。潜变量维度 = 真参数个数（C1 4、C2 4、C3 6、CR3 4、CR4 3）。
- **Z 提取：** 每个被试用全部试次作上下文，取后验均值。
- **旋转测试：** 与 `metric_lab/02_blind_nn_rotation` 同一套方法：对冻结 decoder 的二阶导数能量矩阵（10 种推断）× 132 个简单性指标，从随机旋转出发全局搜索；**T 只用于事后评价**（匈牙利匹配后的 MCC、最差匹配、泄露均值、泄露最大）。**监督旋转上限** = 用 T 做 Procrustes 得到的旋转（任何盲方法的参照）。

## 2. 文件与复现

| 文件 | 作用 |
|---|---|
| `common.py` | 路径、模型列表、潜变量维度、R²、种子 |
| `gen_data.py` | 生成 5 个数据集到 `data/`（含 `*_meta.json`：噪声 sd、实现的 R²） |
| `np_model.py`、`train.py` | 回归 NP 与训练（支持断点续训：每 5 epoch 存 `checkpoints/<模型>_resume.pt`） |
| `run_train_all.sh` | 一次一个模型依次训练（可重复运行，已训完的跳过） |
| `extract_z.py` | 提取 Z，写 `results/<模型>_latent*.npz/json` 与 `rotation/meta_<模型>.npz` |
| `rotation/infer.py` | 10 种推断 → 能量矩阵 `rotation/moms/` |
| `rotation/metrics.py`、`rotation/grid.py` | 132 个指标与并行搜索网格 → `rotation/grid_results.csv` |
| `rotation/analyze_light.py`、`headline.py` | 汇总（`results/rotation_summary.txt`）与热力图（`results/heatmap_*.png`） |
| `run_rotation_one.sh`、`run_rotation_light.sh` | 一个/几个模型的完整（轻量）旋转测试，**仅用 CPU** |

顺序：`python gen_data.py` → `./run_train_all.sh` → `./run_rotation_one.sh <MODEL>`。`data/` 与 `checkpoints/` 约 0.8 GB，已在 `.gitignore` 中。

## 3. NP 训练结果

| 模型 | X 维 | T 维 | 噪声 sd | 最佳 / 总 epoch | 测试 R²(y) | 测试 R²(真 logit) | 分钟 |
|---|---|---|---|---|---|---|---|
| C1 | 3 | 4 | 0.498 | 303 / 353 | 0.8000 | 0.9937 | 16.2 |
| C2 | 4 | 4 | 0.659 | 451 / 500 | 0.8013 | 0.9927 | 23.8 |
| C3 | 4 | 6 | 0.825 | 494 / 500 | 0.8003 | 0.9862 | 23.3 |
| CR3 | 6 | 4 | 0.698 | 438 / 488 | 0.7930 | 0.9945 | 24.6 |
| CR4 | 6 | 3 | 1.509 | 500 / 500 | 0.7955 | 0.9968 | 25.2 |

五个网络都达到了噪声上限（R²(y) ≈ 0.80），对**真实 logit** 的 R² 为 0.986–0.997，说明学到的是函数而不是噪声。（测试集只有 1200 个被试，R²(y) 略高于 0.80 是抽样波动。）

## 5. 旋转测试结果（132 个指标 × 10 种推断 × 5 个模型 = 6600 个组合）

**判通过的标准（用户指定）：** MCC 距监督上限不超过 0.05，**且泄露最大值：C 系列 < 0.2、CR 系列 < 0.3**。严格标准（我加的参照）：MCC 差 ≤ 0.03，泄露最大 ≤ 0.15。

| | C1 | C2 | C3 | CR3 | CR4 |
|---|---|---|---|---|---|
| 通过的组合数（共 1320 个/库） | 561 | 393 | **11** | **1** | 49 |
| 严格通过的组合数 | 546 | 371 | 2 | 0 | 43 |

**五个模型同时通过的组合：0 个。** 逐一核对所有模型子集，有共同通过组合的只有：(C1, C2) 352 个、**(C1, C2, C3) 10 个**、(C1, C3) 10 个、(C2, C3) 11 个、(C1, CR4) 25 个。**(C1, CR3)、(C2, CR3)、(C3, CR3)、(CR3, CR4)、(C2, CR4)、(C3, CR4) 都是 0 个。** 即：障碍首先是 CR3（唯一过关的组合在别的库上都不过），其次是 CR4 与 C2、C3 的互斥。三个 C 系列同时通过的 10 个组合中，出现最多的是 `UXcol.a0.ent`（3 个：高斯 Z、有限差分 0.2、三次多项式）和 `UX.log1e-2`（3 个）。

**代表性指标（推断 = 自动微分），MCC，泄露均值 / 最大：**

| 指标 | C1 | C2 | C3 | CR3 | CR4 |
|---|---|---|---|---|---|
| A：rowsp（逐行支撑集稀疏度，a=0.5） | 0.998，.010 / .02 | **0.794，.232 / .62** | **0.892，.101 / .70** | **0.865，.185 / .55** | **0.926，.044 / .12** |
| B：全局 UX 1−Hoyer | 0.998，.009 / .02 | 0.996，.024 / .10 | 0.943，.086 / .46 | 0.867，.161 / .60 | **0.714，.388 / .67** |
| 列熵 `UXcol.a0.ent`（各列等权） | 0.998，.009 / .02 | 0.996，.024 / .10 | 0.965，.084 / .24 | 0.869，.152 / .61 | **0.745，.302 / .68** |
| F3 = zA + zB + zC | 0.982，.051 / .25 | 0.940，.125 / .44 | 0.871，.130 / .55 | 0.862，.213 / .52 | 0.928，.040 / .09 |

**各模型的最好组合（任意推断 / 指标）：** C1 0.998（.009 / .02）；C2 0.997（.021 / .07）；C3 0.988（.041 / .13，高斯 Z 积分 + 列熵）；CR3 0.930（.116 / .39 或 .140 / .27，多项式代理 + rowsp 一族）；CR4 0.928（.037 / .09，核回归 + rowsp）。

**读法：**
1. **C1、C2 容易，C3 较难：** 全局 / 按列的 UX 集中度类指标（B、列熵、POOL、UXcol）能在多种推断下接近监督上限；C3 最难，只有 11 个组合过关（UXcol、UX、POOL 三类）。
2. **CR4 由 rowsp 一族解决：** rowsp（自动微分）MCC 0.926、泄露 0.044 / 0.12，几乎等于上限（0.929，0.024 / 0.044）；而 B、列熵在 CR4 上失败（0.71–0.75，泄露最大约 0.67）。
3. **CR3 是瓶颈：** 6600 个组合里只有 **1 个**过关——三次多项式代理 + rowsp（a=0.75）：MCC 0.930，泄露 0.140 / 0.272；它在别的库上不过（C3 0.817，泄露最大 0.59）。其余推断下 CR3 最好约 0.87，泄露最大 0.5–0.6。
4. **两族指标的分界仍然存在：** C3 的通过者（POOL / UXcol / UX 全局集中）与 CR4 的通过者（rowsp / UXrow 及含 rowsp 的融合）**没有任何交集**。回归 NP 提高了 Z 的信息量，没有消除这条分界。
5. 与二元选择版相比：C 系列更容易（更多组合通过，MCC 更接近 1），但没有出现跨 C / CR 的普世指标。
6. 之前为救 CR4 而加入的 UU 自占比项（F3 的 C 项）在这里**让 C2、C3 变差**（F3 在 C2 0.940、C3 0.871），因为回归设定下 CR4 靠 rowsp 本身就够。

## 6. 限制

- 每个模型只有**一个** NP 训练和一个 S1 数据集；结论没有在独立重训的 NP 上复现。
- 结果是在已看到 T 的情况下读取的；6600 个组合里挑最好的会有选择偏差，上面"通过数"和"同时通过"是主要证据，"最好组合"只作参考。
- 通过标准为用户指定的泄露上限（C 系列最大泄露 < 0.2，CR 系列 < 0.3）加上我取的 MCC 差 ≤ 0.05；换标准会改变通过数（例如 C 系列用 0.25 时 C3 有 29 个通过）。
- X 的评价分布取自各模型自己的输入分布（设计信息），不是 T，也不是解析式。
- 噪声定义为方差占比 20 %（见 §1）。
- 并行搜索的预算为 400 个起点取 8 个，d = 6（C3）时部分失败可能是搜索不够（在原二元设定下对 C3 观察到过）；这里没有对 C3 做加强搜索。


## 7. S9 / S9_2 式旋转扫描与解析式–神经网络相关
对 10 个回归 NP 做与二元版 S9/S9_2 相同的旋转扫描（指标随角度、解析式 vs 神经网络相关、最小值点角度）：见 [`s9_curves/README.md`](s9_curves/README.md)。要点：C 系列上全局 / 按列指标的最小值精确落在 R*，解析式与神经网络相关 ≥0.99；CR3、CR4（nn1）上只有 rowsp / Fz.A+B+C 一族的最小值落在 R*（91–100% 的扫描），全局指标的最小值偏离 R* 约 14–26°，且解析式本身也如此；CR4 r2 是训练失败的 NP。
