# 04.3 — First-wave candidate metrics and inference methods

**Status:** proposed experiment plan, not implemented or validated.  
**Scope:** the first rotation-sweep experiment of [04.2](04.2_first_experiment_rotation_sweep.md), under the Hessian-energy definition of [04.1](04.1_hessian_energy_simplicity.md).  
**Background library:** [Hessian mean-squared curvature energy](../01_metrics/01_hessian_mean_squared_curvature_energy.md).  
**Objective:** screen pairs of a simplicity metric and an inference method, without tuning either to a particular true parameterization. This is a finite local screen for Gaps 1 and 2 of [03](03_simplicity_search_principle.md), not a global rotation search or evidence of Gap 3.

## 1. Experimental factors and notation

For each test bed, observation type, trained NP and S9/S9_2 coordinate variant, use the existing supervised reference and rotation sweeps of 04.2. Let

$$
U=RZ,\quad W=(U,X),\quad h_{ij}(w)=\partial_{ij}g(w),\quad M_{ij}(R)=E_Q[h_{ij}(W)^2].
$$

The response surface $g$ is specified by channel: continuous conditional mean (the noisy-logit model), binary logit, or binary probability. The energy matrix $M$ is the H matrix of 04.1. Write $A=M^{UU}$, $B=M^{UX}$, and $C=M^{XX}$. Let $k=\dim U$, $p=\dim X$. Metrics may use only these energy matrices; inference may use the allowed data/decoder. An observed choice is a stochastic draw, not a differentiable response surface.

The experiment is a factorial design, with separate IDs for:

1. metric functional $\phi$;
2. energy-matrix block and normalization;
3. inference method and information source;
4. evaluation measure $Q$;
5. output channel, coordinate variant and test bed.

Do not collapse these factors into a single method name. A successful result needs to identify which factor made the difference.

## 2. Mathematical controls before screening

### 2.1 Coordinate and measure invariance

Use the same evaluation points and weights in the underlying physical coordinates for every rotation. If $U=RZ$, the corresponding law is the pushforward of the original $Z$ law, not a newly fitted independent Gaussian for each $R$.

For orthogonal $R$, writing the pointwise derivative blocks in the unrotated frame as $h_{ZZ}$ and $h_{ZX}$,

$$
h_{UU}=Rh_{ZZ}R^\top,\qquad h_{UX}=Rh_{ZX},\qquad h_{XX}=h_{XX}^{(0)}.
$$

Consequently $\sum_{ij} A_{ij}$, $\sum_{ia}B_{ia}$, each column total $\sum_i B_{ia}$ and $C$ are invariant, for a common measure. Include them as negative/sanity controls, not candidate minimizers. Rotating the already-squared matrix is invalid.

For the S9_2 variant, differentiate with respect to $Z_{\rm std}$ before rotating. If the decoder expects raw $Z$, reconstruct it with the saved means and SDs. Use a fixed, saved X standardization in both oracle and inferred surfaces; chain-rule factors matter. Do not silently re-standardize each rotated U. S9_2 is marginal standardization, not full covariance whitening.

For oracle calculations use the standardized T coordinates and the sweep $G$; for inference use the applicable Z frame and $R=GR^*$. These are corresponding sweep labels, not identical functions of identical coordinates unless the alignment is exact.

### 2.2 Output channels

| ID | Observed/fitted surface | Oracle target |
|---|---|---|
| Y-C | continuous Y, conditional mean | true $\eta$ |
| Y-L | binary choices with logistic likelihood, or decoder logit | true $\eta$ |
| Y-P | binary choices with probability target, or decoder probability | $\sigma(\eta)$ |

For the binary decoder, use class-1 minus class-0 logits, not one arbitrarily selected class logit. Convert the continuous decoder output back to logit units using training Y statistics.

$$
\nabla^2\sigma(\eta)=q(1-q)\{\nabla^2\eta+(1-2q)\nabla\eta\nabla\eta^\top\}.
$$

Y-L and Y-P are different estimands; success in one does not imply success in the other. A choice-only infer method can target Y-L via a logistic model or Y-P via a conditional probability estimator; never differentiate raw 0/1 draws. Use the sigmoid here as a stated experimental link convention, not knowledge of the true generating formula. In a real binary task the latent link may not be identified without such a convention.

### 2.3 Fixed-bank boundary and identification issue (mandatory)

CR3 and CR5 have fixed continuous-valued design points. A derivative with respect to X at a bank point is not nonparametrically identified from responses at that finite bank alone: many smooth extensions agree at all bank points but have different X derivatives. Decoder/proxy derivatives impose extrapolation/smoothness assumptions. Mark this limitation, particularly for UX. UU can instead be learned across subjects at the given X under regularity assumptions.

CR3 has an additional mathematical issue: the power function $x^\alpha$ for $0<\alpha<1$ may have an undefined or divergent X derivative at zero amounts. The fact that the value at zero is defined as zero does not define its derivative there. Inspect the actual oracle implementation. Do not silently set undefined derivatives to zero, clip them, or replace infinity with a finite value.

Report two distinct specifications where applicable:

- Full-design M: evaluate the mathematical derivative on the full design; mark any undefined or nonintegrable entries and affected metric/channel invalid.
- Interior-X M (separate, explicitly labeled estimand): for each X coordinate whose derivative is needed, average only over points where that coordinate is locally interior (e.g., positive amount; probability strictly inside its domain). Apply the same mask to every U row of that X column, both oracle and infer, and across rotations. Record coverage; UU may still use the full bank when finite. Use the same generic domain rule for all models, not a rule selected to improve CR3.

An additional all-positive-X complete-case analysis may be reported, but is a different design. Neither masking nor finite-difference smoothing establishes success on the original undefined estimand.

### 2.4 Identifiability checks

Full-Z linear predictability does not imply exact orthogonal recovery. Save the matched correlations and leakage of R* in each variant. C1 has an intercept axis invisible to its logit Hessian; it may be recovered only as the orthogonal complement of identifiable slope axes. In C2, the linear and quadratic coefficients for attribute 1 can have the same UX support. In C3, the same issue appears for both attributes. Therefore strict support counts may have non-permutation ties even though the original formula is scientifically interpretable. A metric that cannot separate such rotations should fail rather than be rescued by a special case.

## 3. Block 1 — simplicity metrics

### 3.1 Inputs and normalization (common to all metric families)

Use the unique entries of A (upper triangle including diagonal) and all entries of B. C is invariant and is not part of the primary loss. For blockwise metrics, define

$$
E_A=\sum_{ij}A_{ij},\quad E_B=\sum_{ia}B_{ia},\quad
a=\operatorname{vech}(A)/E_A,\quad b=\operatorname{vec}(B)/E_B.
$$

The full Frobenius energy counts UU off-diagonal entries twice; the loss counts each distinct coupling once. This is intentional: the scale is invariant but the support count has no duplicates. Also compare a full-matrix convention with diagonal/off-diagonal multiplicities as a labeled sensitivity analysis, not an interchangeable metric.

For a generic nonnegative vector $v$ let $s=\sum_i v_i$, $q_i=v_i/s$ when $s>0$, and $n=\dim v$. Distinguish support-like penalties on block-scaled $v$ from concentration losses on $q$. All losses below are minimized. Set $0\log0=0$. A zero block is zero curvature (save a flag); concentration is undefined for an all-zero block. If a whole sweep is structurally zero/constant it cannot pass. For joint block loss, ignore a block that is identically zero for the entire sweep under a predeclared numeric criterion, never drop it at selected angles. Also retain absolute energies and scale diagnostics: renormalizing each angle can hide changes in total diagonal energy. Guard near-zero denominators with a single rotation-invariant numeric tolerance based on working precision and reference scale. Do not use T to pick it.

### 3.2 First-wave scalar library (apply to eligible blocks)

The primary distinction is approximate *existence of couplings* versus *concentration of their energy*. All formulas below are project adaptations, not claims that their source papers solve this rotation problem.

| ID | Metric | Formula / definition | Role |
|---|---|---|---|
| M01 | Exact support | number of $v_i>0$ (oracle with structural/numeric-zero verification) | discontinuous oracle diagnostic |
| M02 | Threshold support | $n^{-1}\sum_i 1[v_i>\delta]$ | interpretable near-zero count, noise sensitive |
| M03 | Soft L0 (rational) | $n^{-1}\sum_i v_i/(v_i+\delta)$ | primary approximate support |
| M04 | Soft L0 (exponential) | $n^{-1}\sum_i(1-e^{-v_i/\delta})$ | alternative saturation shape |
| M05 | Multiscale Soft L0 | average of M03 over fixed log-spaced $\delta$ | primary robust support proxy |
| M06 | Log-sum | $n^{-1}\sum_i\log(1+v_i/\delta)$ | concave sparsity penalty |
| M07 | Fractional power | $n^{-1}\sum_i v_i^r$, $0<r<1$ | smooth away from zero, sparse energy |
| M08 | Shannon entropy | $-\sum q_i\log q_i/\log n$ | concentration, scale free |
| M09 | Effective support | $1/(n\sum q_i^2)$ | concentration; effective occupied fraction |
| M10 | Hoyer complement | $(\|v\|_1/\|v\|_2-1)/(\sqrt n-1)$ | concentration, zero = one active entry |
| M11 | Gini complement | $1-\sum_{ij}|v_i-v_j|/(2(n-1)s)$ | zero = one active entry |
| M12 | Tail mass | $\sum_{i>m}q_{(i)}$, sorted descending | top-m concentration |
| M13 | Tail RMS | $\sqrt{\sum_{i>m}q_{(i)}^2}$ | concentrates on larger residual couplings |

Handle singleton vectors as non-informative, not passes. The above M11 is finite-n normalized. M09 has minimum $1/n$, not zero; for an equal-weight combination use $(M09-1/n)/(1-1/n)$. M08, M10 and M11 have range [0,1]. Exact support M01 may be divided by n for joint objectives. Normalized concentration metrics treat many weak couplings differently from true support counts; report rather than conflate them.

**Fixed initial settings (proposals, not fitted hyperparameters):**

- M02–M06: $\delta=c/n_0$ with $c\in\{0.01,0.03,0.1,0.3,1\}$, where $n_0$ is the size of the parent block whose energy is the denominator. Use the same threshold for every component of the parent block, including UU sub-blocks. M05 averages all five values. Thus delta is on normalized energy, not derivative amplitude. Optionally use RMS amplitude $\sqrt{v}$ as a separately labeled sensitivity run with its own predeclared threshold scale.
- M07: $r\in\{0.25,0.5,0.75\}$.
- M12/M13: $m=\max(1,\lceil fn\rceil)$, $f\in\{0.10,0.25,0.50\}$, excluding $m=n$ as trivial. No true number of active terms is supplied.
- No per-model or per-rotation tuning. Keep every declared parameter setting as an individual result and report stability across settings. M05 avoids dependence on just one cutoff but does not eliminate hyperparameters.

For M03, very small delta approaches hard support with flat gradients away from zero; very large delta approaches a linear energy functional and loses rotation sensitivity. This is why the grid and threshold-averaged version are needed.

### 3.3 Structural metric recipes

Use the following block recipes with the scalar library; not all Cartesian combinations are informative. The recipes are symmetric under latent-axis signs and permutations.

| ID | Recipe | Initial scalar metrics | Scientific hypothesis |
|---|---|---|---|
| B01 | flatten UX, block normalized | M01–M13 | few parameter-stimulus couplings |
| B02 | unique UU entries, block normalized | M01–M13 | few second-order latent couplings, including self-curvature |
| B03 | UU diagonal only, normalized by full UU energy | M02–M07; sum of diagonal share as control | many latent axes have simple linear dependence |
| B04 | UU off-diagonal only, normalized by full UU energy | M02–M07; sum of off-diagonal share as control | fewer interactions among latent variables |
| B05 | UX columnwise, equal-column mean | M03,M05,M07–M12 | each stimulus is modulated by few latent axes |
| B06 | UX columnwise, column-energy weighted | same as B05 | strong stimulus couplings receive greater weight |
| B07 | UX rowwise, equal-active-row mean | M03,M05,M08–M12 | each latent axis acts on few stimuli |
| B08 | UX rowwise, row-energy weighted | same as B07 | avoid a tiny noisy axis dominating the loss |
| B09 | joint UX + unique UU, separate normalization | M03,M05,M06,M07,M08,M09,M10,M11 | both between-parameter and stimulus couplings matter |
| B10 | UX + UU diagonal and off-diagonal separately | M03,M05,M07 | distinguish self-curvature and mixed curvature |
| B11 | UX row-total concentration | M08,M09,M10 | secondary diagnostic; may reward inactive axes rather than identifiable axes |
| B12 | spectral concentration of energy matrix A or B | effective rank / min(k,p), stable rank / min(k,p) for B; divide by k for A | secondary exploratory diagnostic, not a low-dimensionality claim |

For B05/B06, normalize each nonzero column by its own sum before applying a scalar metric; column energies are rotation invariant. Use the column size k as $n_0$. For B07/B08 use row-local normalization and p as $n_0$, record all-zero row flags; report active row count and use weighted variant as primary among row-local recipes. For B09 choose weights $(w_B,w_A)=(0.5,0.5)$ and $(0.75,0.25),(0.25,0.75)$ as predeclared sensitivity settings, with the rule for identically zero blocks above. Combine comparable [0,1] scores (M06/M07 divided by their fixed attainable upper bound or a fixed dimension-only bound); store both components. For B10 use equal weights for B, diagonal A and off-diagonal A, with sensitivity analysis treating A as a single block. A zero sub-block contributes zero support; do not remove it because it vanishes at one angle. B03 and B04 alone are controls: $f(a,b)=ab$ becomes a difference of squares after 45-degree rotation, so interaction-only minimization can reward a more complicated representation.

For M08–M13, row/column local normalization is already part of the definition; no additional per-angle reweighting except the declared row-energy weighted recipe. Do not assume B11/B12 should win: concentration may collapse several scientifically distinct effects.

### 3.4 Conditional energy matrices (optional second batch within wave 1)

For a predefined partition of X into groups S,

$$
M^{(s)}(R)=E[h(W)^2\mid S=s],\qquad L(R)=\sum_s\omega_s\phi(M^{(s)}(R)).
$$

The same $\phi$ must apply to every group. Compare group-equal and group-frequency weights. A generic X-only partition can use a fixed-seed clustering or fixed quantile bins computed once, without T/Y or the supervised reference. Keep minimum group coverage and sample counts. Known bank trial types may be used only as a separately reported design-metadata arm if such labels are available to the real analyst, not as a universal method or hidden parameter-specific rule. Do not choose the grouping or weight by oracle performance. Nonlinear $\phi$ makes conditional-then-average different from pooled M.

## 4. Block 2 — inference methods

Every method estimates the same channel-specific M or its derived metric. Inference methods may not use T, true f, oracle logits/probabilities, or true derivatives. Oracle is a separate evaluation arm. Fit methods once in the unrotated Z frame and transform derivatives to every R where possible. Per-R refits, if investigated, are a separate diagnostic because regularization and basis selection can be coordinate dependent.

### 4.1 Frozen decoder available (no additional function fit)

| ID | Method | Implementation | Priority |
|---|---|---|---|
| I01 | Exact automatic differentiation | per-point Hessian via torch.func.hessian + vmap, batched, eval mode | P0 reference for decoder |
| I02 | Central finite differences | scalar forward queries; diagonal three-point, mixed four-point stencil | P0 check and black-box method |
| I03 | Gradient finite differences | compute two gradients per coordinate, central difference, symmetrize | P1 efficiency/validation |
| I04 | Local polynomial on decoder queries | balanced local perturbations, quadratic/cubic fit, derivative at center | P1 smoothed derivative estimate |

For I02, with fixed coordinate-specific step sizes,

$$
\hat h_{ii}=\frac{g(w+he_i)-2g(w)+g(w-he_i)}{h^2},\quad
\hat h_{ij}=\frac{g(w+h_i e_i+h_j e_j)-g(w+h_i e_i-h_j e_j)-g(w-h_i e_i+h_j e_j)+g(w-h_i e_i-h_j e_j)}{4h_i h_j}.
$$

Use steps in standardized coordinates (initial grid 0.01, 0.03, 0.10; 0.003 for float64 convergence checks); compare convergence and cancellation. Use double precision if feasible. Bound-aware stencils or exclusion must be declared; a symmetric stencil may evaluate outside the domain. I04 bandwidth is a smoothing parameter, not the exact same pointwise derivative at finite bandwidth. I01 estimates the decoder Hessian accurately, but is not an oracle for the true generating function.

### 4.2 Fit a surrogate from allowed WY

Two input sources are separate experimental factors:

- D0 = observed Y; subject-level train/validation split; continuous squared loss or binary logistic likelihood. Estimate conditional mean/logit as specified.
- D1 = frozen-decoder deterministic output, at observed W or permitted extra queries; distillation using squared loss on logits/continuous output, or a probability loss on soft labels (binary cross-entropy with soft targets or MSE). Decoder-sampled choices are optional negative control D2, not the default because they discard information.

| ID | Method | How to infer Hessian | Initial settings / limitations |
|---|---|---|---|
| I05 | Global polynomial ridge / logistic ridge | analytic derivatives of complete total-degree basis | degrees 2,3,4; degree 5 optional, regularization by held-out subjects; not only pairwise terms |
| I06 | Orthogonal polynomial / PCE surrogate | derivative basis and numerical integration or derivative Gram matrix | Hermite/Legendre where justified; total degrees 2–4; empirical evaluation for correlated Z or fixed X |
| I07 | Local polynomial regression | quadratic/cubic weighted least squares (continuous/soft labels), local likelihood (choices) | kNN bandwidth grid 256,1024,4096 where sample size allows; check unique subjects and rank/conditioning |
| I08 | Smooth RBF / kernel ridge | differentiate RBF kernel basis analytically | isotropic scaled Gaussian kernel; landmark or Nyström 256,1024,2048; tune kernel bandwidth and ridge by held-out predictions |
| I09 | Gaussian-process surrogate | derivative of posterior mean; posterior derivative uncertainty separately | smooth RBF or Matérn 5/2; sparse/inducing GP; 256/512 inducing points; binary GP classification if available |
| I10 | Penalized spline / tensor-product GAM | analytic or AD derivatives of spline basis | univariate and bivariate smooths; allow higher-order tensor terms in separate sensitivity model; pairwise-only restriction can bias higher-order interactions |
| I11 | Smooth MLP surrogate | AD on trained GELU/tanh decoder proxy | width 64/128, 2–3 layers; validation-based regularization, multiple seeds |

Polynomial approximations use all W dimensions on equal footing (no special known generator features or parameter interactions). PCE is distinguished from ordinary polynomial ridge by basis/measure; if the two span the same polynomial space with equivalent regularization and fitting, label the redundancy rather than claim independent evidence. Standard product orthogonality cannot be assumed for a fixed bank or correlated latent distribution. For GP, posterior expected derivative square = squared posterior derivative mean + derivative posterior variance; report separately, since the variance term is not estimated structural curvature of a single fixed surface. For binary D0, KRR/RBF probability regression is permissible for Y-P; Y-L requires a smooth kernel logistic fit or another predeclared probability-to-logit transform with clipping sensitivity. Do not apply logit directly to raw binary observations.

Use subject-held-out predictive validation for hyperparameters, never minimum-angle or oracle-derived scores. Predictive validation alone cannot validate derivatives. Preserve the held-out loss, degree/bandwidth, fit time and sample coverage.

### 4.3 Direct / bias-reduced energy estimators

| ID | Method | Definition and caveat | Priority |
|---|---|---|---|
| I12 | Cross-fitted product of independent derivative estimators | average $\hat h^{(1)}_{ij}(w)\hat h^{(2)}_{ij}(w)$, fits use disjoint subject sets and common independent evaluation points | P1 |
| I13 | Direct series quadratic-functional estimator | use a fixed basis and cross-subject response-pair products, estimate derivative Gram quadratic form without fitting a response surface | P2 feasibility |
| I14 | Matched local finite differences from observed WY | exact/reliably matched stencils or local contrast weights, independent replicates for squaring | P2 feasibility |

I12 can reduce upward squaring bias from independent centered estimation errors, but does not remove shared smoothing bias or guarantee conditional independence if fits share training information. With Z obtained from the same trained NP, independence is approximate/conditional on that NP. Preserve signed raw estimates; clip negative entries to zero only for a clearly labeled nonnegative metric-input version. Report negative fraction and magnitude.

For I13, one possible construction on a continuous mean or probability channel uses a fixed orthonormal basis $\{\psi_r\}$ for Q (or a basis orthonormalized on an independent design sample). Let $\psi$ be the vector and

$$
D^{ij}_{rs}=E_Q[\partial_{ij}\psi_r(W)\partial_{ij}\psi_s(W)].
$$

For independent observations from Q with mean response g, $\mu=E[Y\psi(W)]$. The projected function has energy $\mu^\top D^{ij}\mu$. An off-diagonal pair statistic is

$$
\widehat M^{ij}_{\rm series}=
\frac{1}{N(N-1)}\sum_{n\ne m}Y_nY_m\psi(W_n)^\top D^{ij}\psi(W_m).
$$

The displayed iid-row formula is NOT the estimator to use directly on clustered project data. Under independent, identically sampled subjects and equal-subject Q, replace $Y_n\psi(W_n)$ by the within-subject average vector and form pairs of distinct subjects; the expectation targets the corresponding projected energy when the basis/Gram are fixed independently and the sampling law matches Q. Otherwise use appropriate design weights or declare unsupported. This estimates projected energy, not exact M at finite basis dimension; no general direct-logit estimator follows from this linear moment identity. Fixed bank X derivative extension remains assumed. I14 is unlikely to work well in high-dimensional random designs without controlled querying; do not present nearest neighbors as exact stencil observations or square noisy contrasts as unbiased energy.

Methods I12–I14 are exploratory. They distinguish derivative-squaring bias from model approximation error. Direct L estimation without explicit M is left open: any proposed estimator must target the declared $\phi(M)$ rather than silently substitute a different interaction statistic.

## 5. Evaluation measure Q (crossed with inference, not a metric family)

| ID | Latent part | X part | Purpose |
|---|---|---|---|
| Q01 | empirical subjects | observed trials within each subject | primary, subject-equal mean |
| Q02 | empirical subjects | empirical X distribution (complete vectors) or exact shared bank | controlled product evaluation |
| Q03 | fitted joint Gaussian in Z frame; oracle uses true T distribution or separately labeled fitted Gaussian in standardized T frame | known sampling distribution for oracle; empirical joint X or an X-only fitted sampler for infer | distribution-based evaluation |
| Q04 | fitted joint Gaussian Z | exact shared 500-row bank | hybrid measure for fixed bank, no distribution model for X |
| Q05 | independent standard-normal Z after appropriate preprocessing | as Q03/Q04 | sensitivity only; approximate prior assumption |

Q01 uses $(1/S)\sum_s(1/n_s)\sum_t$; row-equal average is a separately labeled alternative. Q02 product design is not necessarily the observed joint law; in these simulations T and X are designed independently, but real data may violate this. Q03 must not pass the oracle X generator into blind inference unless the design distribution is genuinely supplied to the analyst. Estimate or resample complete X vectors, never independently shuffle bank columns. Q05 is sampled once in the base frame and pushed forward; do not refit independently at each R. For Gaussian integration report out-of-support frequency and tail sensitivity. A truncated law is another estimand.

Use common random numbers across rotations. Proposed first pilot: 256 evaluation subjects/latent draws, 32 trials/X vectors per draw for random designs, then convergence at 512/64 and 1024/128. For bank Q02/Q04 use all 500 rows at the final fidelity stage; initial fixed subsampling must be common across R and reported. Pilot seeds 31, 73, 101; subject-level bootstrap for uncertainty when meaningful. Compare paired analytic/inferred curves using the same measure specification and sampling protocol, with oracle and infer coordinate distributions documented (they may differ due to imperfect NP recovery).

## 6. Efficient implementation: cache derivative second moments

One expensive derivative pass can support every metric and all rotations. Save, in the base coordinate frame,

$$
K_{abcd}=E[h^{UU}_{ab}h^{UU}_{cd}],\qquad
J^{(x)}_{ab}=E[h^{UX}_{ax}h^{UX}_{bx}].
$$

Then

$$
A_{ij}(R)=\sum_{abcd}R_{ia}R_{jb}R_{ic}R_{jd}K_{abcd},\qquad
B_{ix}(R)=\sum_{ab}R_{ia}R_{ib}J^{(x)}_{ab}.
$$

Use G in the oracle base frame and R in the infer base frame. For masked UX use the same column-specific mask for J and every U direction. This is not an additional simplicity metric; it is an exact computational contraction under a fixed measure. It avoids millions of repeated decoder derivative evaluations. For k=6 the full UU tensor has only 1296 elements. Keep raw pointwise Hessians for a small audit set, stream moments in float64, verify against direct AD or finite differences after rotation. Do not use only M at identity to derive the rotated M; it lacks cross-products.

## 7. First execution queue (proposed)

The experiment should be broad but staged, rather than one enormous Cartesian product.

| Batch | Models/channels | Metrics | Infer and Q | Purpose |
|---|---|---|---|---|
| A | all available models; Y-C/Y-L/Y-P | all B01–B12 recipes as eligible | oracle, Q01/Q02 | eliminate invariants, analytic failures and undefined estimands |
| B | all available valid NP runs, both S9/S9_2 | same registry as A (including failed oracle controls) | I01/I02 × Q01 | first decoder-fidelity and numerical screen |
| C | same | same registry; emphasize M03/M05/M07/M08–M13, B01/B02/B05/B09 | I01 × Q02/Q03/Q04/Q05 where valid; I03/I04 spot checks | averaging-rule and smoothing effects |
| D | continuous and binary, all models as resources permit | predeclared primary panel and all retained oracle candidates | I05/I06/I07/I08/I11 × D0/D1, Q01 | test data-only and distillation inference |
| E | selected candidates by a declared development protocol | same metric and settings, not model-specific | I09/I10/I12, optional I13/I14 and conditional groups | expensive or assumption-heavy extensions |

A–C are the immediate first run. D/E are planned expansions of wave 1, not claimed implemented. The primary panel is B01/B02/B05/B09 with M03/M05/M07/M08/M09/M10/M11/M12, plus B03/B04 and invariant negative controls. M01 serves as an analytic diagnostic. Retain p-channel results even if logit does better. Do not treat the absent continuous CR5 as a failed method: mark missing/not run. Respect Stage A thresholds and record excluded NP replicates.

The purpose of screening against all test beds is method development; it is not an unbiased estimate of generalization. Freeze the candidate registry and settings before execution. Use new simulation seeds, NP training replicates, and ideally new generating functions as confirmation after selection. Report all screened settings, not only winners. Selection is evaluation-stage use of synthetic truth, never an input to any blind estimator or per-model tuning.

## 8. Evaluation and outputs

Follow [04.2](04.2_first_experiment_rotation_sweep.md) exactly for reference R*, sweep sets, angles, baseline handling and perfect/marginal criteria. For k latent dimensions, the documented plan has $2^k-k-1$ subsets and $1+6(2^k-k-1)$ labeled evaluations after removing duplicate 0-degree baselines (25, 67, 343 for k=3,4,6). Retain the angle labels; if exact rotation matrices are repeated additionally, record canonical keys and a deduplicated sensitivity view. Do not collapse all signed-permutation endpoints into one merely because a valid metric should be invariant to them: those endpoints are also useful implementation checks.

For each metric/infer pair:

- Pearson and Spearman across rotations per 04.2; also per-curve correlations with constant curves marked NA, not zero.
- Per-sweep analytic/inferred minimum angle and perfect/marginal/fail status. A constant or undefined curve does not pass. In addition to the official convention, report whether an interior angle ties the endpoint minimum, since this is not unique identification.
- Dynamic range, endpoint-equivalence error, interior-minus-endpoint margin, and fraction of sweeps with a strict positive margin against 15–75 degrees. High correlation alone does not ensure a useful minimum.
- M-matrix relative error (where nonzero denominator), block error, rank agreement, false-positive energy in oracle-zero entries, and inferred versus analytic normalized loss error. Oracle-zero diagnostics are evaluation only.
- Subject bootstrap / quadrature variability, predictive holdout error, runtime and peak memory. Distinguish numerical failure, undefined target, constant curve, missing result, and true metric failure.

Suggested files (proposal, not existing paths):

    run_manifest.json
    rotation_manifest.csv
    energy_matrices.npz
    derivative_moments.npz
    metrics_long.csv
    correlations.csv
    sweep_minima.csv
    pass_summary.csv
    fit_diagnostics.csv

Each row carries model, NP replicate, beta, channel, coordinate variant, measure ID, seed, metric ID, block recipe, hyperparameters, infer ID, source ID, rotation ID, subset, angle, value, validity and reason. Save transformation parameters, masks and integration weights; do not overwrite raw signed or invalid estimates. Separate oracle outputs from blind inference inputs at the code and file levels.

**Acceptance:** a candidate passes the local screen only under the official all-sweep criterion for both analytic and inferred values. Report strict-tie diagnostics separately. No claim of a universal metric or global optimality follows from this screen; the next stage requires general orthogonal rotations, multiple starts, and independent confirmation.
