# 02 — Test beds

This note lists the simulated test beds (toy models) used at the current stage. There are **two classes of toys, six models each: 12 independent toy models in total.** The toy names are the model IDs of the code.

- **Class B — binary-choice toys:** `C1`, `C2`, `C3`, `CR3`, `CR4`, `CR5`. The generating model produces a binary choice `Y ∈ {0, 1}`.
- **Class C — continuous-output toys:** `C1L`, `C2L`, `C3L`, `CR3L`, `CR4L`, `CR5L` (`<MODEL>L`, "noisy logit"). The generating model produces a continuous noisy logit `Y = η + ε`.

Each of the 12 toys is a separate test bed: its own observed data, its own trained Neural Process (NP), its own rotation sweeps and its own results. A conclusion is stated per toy and per class. Results of the binary class must not be read as results of the continuous class, or the other way round.

**What is shared and what is specific.** The two classes share the same underlying cognitive/choice structure for each model family `C1, C2, C3, CR3, CR4, CR5`: the prior of the parameters `T`, the stimulus design `X` and the true-logit function `η(X, T)` (sections 3–6). Everything related to the observation is specific to the class (section 1): the observed `Y`, the noise, the NP likelihood and loss, the decoder output, the output channels of the screening experiments, the β of the NP and the achievable supervised ceiling. The experimental framework (04.1–04.3: supervised reference, rotation sweeps, metric × inference screening, evaluations 1 and 2) is the same for all 12 toys.

Notation. Each toy defines a scalar `η(X, T)` for every trial, which we call the **true logit** of its model family. For C1–C3 `η` is linear in `T`. For CR3–CR5 `η` is a cumulative-prospect-theory (CPT) value difference scaled by `τ`.

## 1. The two classes of toys: what is specific to each

| | Class B — binary choice (`C1` … `CR5`) | Class C — continuous output (`C1L` … `CR5L`) |
|---|---|---|
| Observed `Y` | `Y ~ Bernoulli(p)`, `p = sigmoid(η(X, T))` | `Y = η(X, T) + ε`, `ε ~ N(0, s²)` independent across trials |
| Noise | Bernoulli sampling | `s² = Var(η) · (1 − R²) / R²`, `R² = 0.8` (the **signal ratio**) |
| What a perfect predictor knows | `η`, hence `p` | `η`; it explains 80% of the variance of `Y`, the other 20% is irreducible |
| S2 precheck | binary-choice MLE recovery and Fisher information | Gaussian MLE recovery, Fisher information and the realised signal ratio |
| NP reconstruction loss | cross-entropy (two-class decoder) | mean squared error on `Y` standardised with the TRAIN mean and SD (one-output decoder); `+ β·KL` as in class B |
| NP training (S3) | β = 5·10⁻⁴, at most 500 epochs, patience 50 | β chosen per toy without `T` (section 1.2), at most 5000 epochs (C1L, C2L: 500), patience 50 |
| Decoder output used as the response surface | class-1 minus class-0 logit (Y-L) or its sigmoid (Y-P) | continuous output converted back to logit units with the TRAIN `Y` scaler, `out · SD + mean` (Y-C) |
| Output channels of the 04.3 screening | Y-L, Y-P | Y-C |

Both classes go through the same stages: data generation `models/s1_generate.py` and precheck `models/s2_precheck.py` (outputs in `outputs/models/`), NP training and S4–S9_2 in `nn/` (outputs in `outputs/nn/<MODEL>/`).

For the continuous toys `Var(η)` is the variance of the true logit over all trials of all subjects in the dataset. With `R² = 0.8` this gives `s² = Var(η) / 4`.

**Independence of the two classes.** Each toy has its own dataset file, its own NP and its own downstream outputs. The two classes are generated by the same model code (`T` prior, `X` sampler, `η`) and from the same random streams for `T`, trial counts and `X` (a subject has the same `T` and `X` in `C1` and `C1L`); the noise of a class C toy has its own stream (seed `777 +` index of the model family). That reuse is a convenience of the current implementation and not a property of the test beds: any toy can be regenerated with new seeds, and replicate datasets and NPs (new subjects, new noise, newly trained NP) are separate runs of the same toy.

The earlier stand-alone experiment `noisy_logit_np/` (its own NP code, C1–CR4 only) used datasets identical to `C1L`–`CR4L`. Its networks are not the class C test beds of this note.

### 1.2 Choice of β for the class C toys

β was chosen without `T`. For each toy an NP with a small reference β (3·10⁻⁴ for CR3L–CR5L) and NPs with several larger β were trained. The selected β is the largest one whose validation R² of `Y` is at most 0.005 below the reference **and** whose `Z` has no collapsed dimension (between-subject variance and KL ≈ 0). The recovery of `T` from `Z` was checked only afterwards. ## 3. C1 — linear logit (4 parameters, 3 stimuli)

- **Parameters** `T = (b1, b2, b3, b4)`, each `b_k ~ N(0, 0.5²)` independently.
- **Stimuli** `X = (x1, x2, x3)`, each `x_j ~ Uniform(−1, 1)` independently.
- **True logit**

  `η = b1 + √3 · b2 · x1 + √3 · b3 · x2 + √3 · b4 · x3`

- `b1` is an overall bias. `b2, b3, b4` are the slopes on `x1, x2, x3`. The factor `√3` gives each design feature unit variance under `Uniform(−1, 1)`.

## 4. C2 and C3 — option comparison with quadratic terms

Both take four raw stimuli `X = (X1_A, X1_B, X2_A, X2_B)`: attributes 1 and 2 of option A and of option B. Each is `Uniform(−1, 1)`, independent. In class B `Y = 1` means option A is chosen.

Parameters: each `b_k ~ N(0, 0.5²)`, independent.

### C2 (4 parameters)

`T = (b1, b2, b3, b4)`

```
η = b1
  + √3      · b2 · (X1_A − X1_B)
  + (√5/2)  · b3 · [ (3·X1_A² − 1) − (3·X1_B² − 1) ]
  + √3      · b4 · (X2_A − X2_B)
```

- `b1` is a bias, `b2` is the linear effect of attribute 1, `b3` is its quadratic effect, and `b4` is the linear effect of attribute 2.
- `η` is nonlinear in `X` but linear in `T`.

### C3 (6 parameters, nests C2)

`T = (b1, …, b6)`

```
η = b1
  + √3      · b2 · (X1_A − X1_B)
  + (√5/2)  · b3 · [ (3·X1_A² − 1) − (3·X1_B² − 1) ]
  + √3      · b4 · (X2_A − X2_B)
  + (√5/2)  · b5 · [ (3·X2_A² − 1) − (3·X2_B² − 1) ]
  + 3       · b6 · (X1_A·X2_A − X1_B·X2_B)
```

- It adds the quadratic effect of attribute 2 (`b5`) and the mixed `X1 × X2` effect (`b6`). With `b5 = b6 = 0` it reduces to C2.
- `η` is linear in `T`, so for C1–C3 the second derivative of `η` with respect to `T` is zero. All curvature is in `X`.

## 5. CR3, CR4, CR5 — cumulative-prospect-theory choice

Each trial is a choice between two lotteries A and B. A lottery has three numbers: a gain amount `g`, a loss amount `l ≥ 0` and the probability `p` of the gain. With probability `1 − p` the subject loses `l`.

`X = (gain_A, loss_A, p_A, gain_B, loss_B, p_B)`, six dimensions.

### Generating function

For a lottery `(g, l, p)`:

```
w(p)  = sigmoid( γ · logit(p) )                      # probability weighting; p clipped to [1e-12, 1 − 1e-12]
V(g, l, p) = w(p) · (g/100)^α  −  λ · w(1 − p) · (l/100)^α
η(X, T) = τ · [ V(lottery A) − V(lottery B) ]
```

- `α` is the curvature of the value function, `λ` (loss aversion) scales losses, `γ` controls the distortion of probabilities, and `τ` is the choice sensitivity (the inverse of response randomness).
- For `g = 0` or `l = 0` the corresponding power term is exactly zero.
- Class B: `P(Y = 1) = sigmoid(η)`. Class C: `Y = η + ε`.

### The three models

| Model | `T` | `α` | `X` sampling |
|---|---|---|---|
| **CR3** | `(α, λ, γ, τ)`, 4 parameters | free | fixed 500-row bank (below) |
| **CR4** | `(λ, γ, τ)`, 3 parameters | fixed at 1 | i.i.d. per trial and subject (below) |
| **CR5** | `(λ, γ, τ)`, 3 parameters | fixed at 1 | the same fixed 500-row bank as CR3 |

CR4 and CR5 use the CR3 formula with `α = 1`. They keep the CR3 prior for `λ, γ, τ`.

### CR4 stimuli: i.i.d. uniform

For every trial of every subject, the six components are drawn independently:

- `gain_A, loss_A, gain_B, loss_B ~ Uniform(5, 200)`
- `p_A, p_B ~ Uniform(0.05, 0.95)`

There is no rejection step and no design optimisation. Some trials may therefore have one lottery that dominates the other.

### CR3 and CR5 stimuli: a fixed 500-row bank

All subjects see the **same 500 rows in the same order**. The bank is built once (design seed `20261023`) and then frozen. It has four trial types:

| Type | Rows | Content |
|---|---:|---|
| `gain_only` | 60 | both lotteries have no loss, different probabilities |
| `gamma_neutral` | 60 | both probabilities equal 0.5 |
| `loss_only` | 40 | both lotteries have no gain, different probabilities |
| `general` | 340 | sampled without replacement from an earlier optimised CR2 4-parameter bank (amounts and probabilities on a grid) |

The amount grid is `{5, 10, 15, 20, 30, 40, 50, 60, 80, 100, 125, 150, 175, 200}` and the probability grid is `{0.05, 0.10, …, 0.95}`. Rows with strict first-order stochastic dominance are excluded, and there are no duplicate or mirrored rows. The CR5 bank has exactly the same rows, order and type labels as the CR3 bank (the code checks this).

Because the bank is fixed, the stimuli are identical across subjects, and the observed difference between subjects comes only from `T`.

## 6. Sampling of T

For C1–C3 see sections 3 and 4: `b_k ~ N(0, 0.5²)` i.i.d. For the CPT models each subject's `T` is drawn independently from the following marginals:

| Parameter | Distribution | Range |
|---|---|---|
| `α` (CR3 only) | `Beta(12, 3)` | (0, 1), bounds `[0.02, 0.999]` |
| `λ` (loss aversion) | `Gamma(shape 9, scale 0.22)`, redrawn when outside the bounds | `[0.3, 5]` |
| `γ` (probability weighting) | `Beta(9, 4)` | bounds `[0.02, 0.999]` |
| `τ` (sensitivity) | normal, mean 2.2, SD 0.55, truncated | `[0.5, 4]` |

The four parameters are drawn independently. CR4 and CR5 use the same draw as CR3 with the `α` column dropped. Out-of-range `λ` values are redrawn, not clipped, so there is no atom at the bounds.

## 7. Summary of the model families

Each row defines two toys, `<model>` (class B) and `<model>L` (class C).

| Model | `dim(T)` | `dim(X)` | `X` | trials / subject | `η` is linear in `T`? |
|---|---:|---:|---|---:|---|
| C1 | 4 | 3 | i.i.d. U(−1, 1) | 300–500 | yes |
| C2 | 4 | 4 | i.i.d. U(−1, 1) | 300–500 | yes |
| C3 | 6 | 4 | i.i.d. U(−1, 1) | 300–500 | yes |
| CR3 | 4 | 6 | fixed 500-row CPT bank | 500 | no |

C1–C3 are the "classic" controls: `η` is linear in `T`, with the nonlinearity only in `X`. CR3–CR5 are the cognitive-model cases, where `T` enters nonlinearly through `α`, `γ`, `λ` and `τ`.
