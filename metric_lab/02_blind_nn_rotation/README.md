# 02 · 盲旋转搜索：冻结 NN 上的 HE 推断 × 简单性指标实验日志

**目标。** 从冻结 Neural Process 的潜变量 Z 出发，不用真实参数 T，找一个正交旋转 R，使 U = R·Z 的各轴与真实参数一一对应。
**测试范围（本轮）：C1、C2、C3、CR4 四个数据库，每个指标每个库至少测一次。**（CR3、CR5 只作旁证，不进入判断。）

本文件是**实验日志**：每一种试过的 *推断* 与 *指标*（成功 / 失败 / 部分成功）都记录在此，并持续追加。理论背景见 [`docs/01_metrics/01_hessian_mean_squared_curvature_energy.md`](../../docs/01_metrics/01_hessian_mean_squared_curvature_energy.md)。

> **状态：探索性。** 所有数字都是在用 T 做事后评价之后才读到的，TEST 集被多次查看，不构成最终验证。见 §7 的限制。

## 0. 底线与评价协议

**底线（来自研究约束）**

1. T / oracle 不进入损失、超参数或方法选择（只做事后评价）；
2. 不用 ICA / 非高斯性；不做 role detection（增益轴、设计类别、参数语义）；
3. 第一步用某种 **推断** 得到曲率能量，**不用解析式**；第二步由曲率能量算 **简单性指标**；第三步指标偏好真实朝向、使 U 与 T 一一对应；
4. 融合指标：**不允许手选权重**；只能直接相加，或权重有独立于解析式 / T 的理论依据。

**评价量**（T 仅在此出现）：对 |corr(U,T)| 做匈牙利匹配，报告 **MCC**（匹配对均值，括号为最差匹配对）、**泄露均值**、**泄露最大**（未匹配相关系数的最大值）。**监督上限** = 用 T 做 Procrustes 得到的旋转（任何盲方法的参照，不是方法）。

## 2. 推断（HE 如何得到）

HE = 逐元素平均平方 Hessian `M = E[H⊙H]`；旋转后需要交叉二阶矩张量（文档式 35–36），故保存全矩 `E[vec(H)vec(H)ᵀ]`（(D²×D²)）。

| 编号 | 推断方法（文档类别） | 状态 | 说明 |
|---|---|---|---|
| I1 | **B1 + B7**：冻结 decoder 完整自动微分 Hessian，在经验 Z × 模型输入分布 X（CR3 为固定 X 库）上平均；logit 通道（class1 − class0）；X 用 `x_std` 标准化；Z 用全局 z_std | **主力** | 全部结果默认用此。N=4096 点，seed 2（另测 seed 5、8）。 |

**坐标约定。** 早期实验（标 ★）把搜索变量参数化为 `(Q·R*)·Z`，其中 R* 是监督旋转（Haar 起点，分布上不泄露，但固定种子时起点受 R* 影响）。后期实验改为 **R\*-free**：U = Q·Z_std，R* 只在评价时出现。
