# Metric Lab 07 — Wave 4-2 first wave: unified benchmark and failure localisation

Implementation of [docs/00_project_flow/wave4-2/01_first_wave_README.md](../../docs/00_project_flow/wave4-2/01_first_wave_README.md) (W1-00 … W1-05) on the 12 formal test beds of [02_test_beds](../../docs/00_project_flow/02_test_beds.md). Independent experiment: it reads S1–S9_2 artifacts, reuses the validated Lab 03 loaders / metric code and the Lab 06 metric library read-only, and writes only under `metric_lab/07_unified_benchmark/results/` and `outputs/metric_lab/07_unified_benchmark/`. No NP was retrained.

## Main findings (2026-11-26)

All numbers come from the tables in `results/` (generated by `analyze.py`, `synthesize.py`, `report.py`); the complete tables are reproduced at the end of this README. Class B and class C are reported separately throughout; channels are not extra toys. These are development results on synthetic truth, not confirmation.

1. **W1-00 gate passed.** 468/468 checks on 12 primary toys × 2 variants and the 5 secondary runs. These cover splits, scalers (including the class C y scaler), subject pairing, rotation counts (29/78/400), R = G R*, C1/C2 closed-form analytic derivatives, CR AD vs FD, decoder equality with the Lab 03 implementation, contraction against direct differentiation of the rotated function, prediction invariance, energy invariance, signed-permutation invariance of all 415 metrics, and label-independent blind scores. FD with step 0.003 / 0.01 SD agrees with AD to 1e-4 / 1e-3 (truncation error scales as h²), so FD is not crossed with the metrics.
2. **W1-01, Q01 pilot, logit/continuous channel, of 415 metrics.** Each count is the number of metrics passing on every library of the scope.

   | | C1–C3 (6 libraries) | CR3–CR5 (6 libraries) | all 12 libraries of the class |
   |---|---|---|---|
   | analytic perfect | 174 | 83 (MASK-ALL) / 85 (MASK-COL) | 53 / 58 |
   | class B: analytic and decoder both perfect | 140 | 1 / 0 | 0 |
   | class C: analytic and decoder both perfect | 139 | 7 / 1 | 0 |

   59 metrics are analytic-perfect on all 24 logit/continuous libraries under at least one mask policy. All 17 historical Lab 03 analytic-perfect metrics are among them. On the CR families the decoder is the bottleneck in both classes: the four-way table has 1040 (B) / 993 (C) analytic-pass / inferred-fail cells and only 9 / 6 inferred-only cells. Y-P is a separate estimand: on CR it has 0 analytic-perfect metrics on all libraries.
3. **W1-02, measures and integration.** Changing the measure (Q01–Q05) changes the counts only slightly: C families 151–161 both-marginal metrics, CR 4–13. The priority panel keeps its all-sweep status in all three seeds in 97–99% of cells at fidelities C and D. Increasing fidelity from 512×64 to 1024×128 does not change the class pattern. The secondary runs (repeat 2, CR3 β = 5e-5) reproduce it: B C-family 123–124 both-perfect metrics over 3 libraries, CR 0.
4. **W1-03, representation vs surface.** The supervised orthogonal bridge B-orth keeps 99–100% of the analytic passes on every CR library of both classes; B-aff keeps 82–99%, except CR4 / CR4L S9_2 at 29% / 60%. The frozen decoder keeps 6–22%.

   | Interpolation | a = 0 (bridge) | a = 0.25 | a = 0.5 | a = 0.75 | a = 1 (decoder) |
   |---|---|---|---|---|---|
   | B-orth → decoder, CR families | ~0.99 | ~0.5 | ~0.37 | ~0.26 | 0.11–0.17 |

   On the C families every arm stays at ~0.98. The supervised ceiling is lower on CR (B: S8 MCC 0.85–0.89; C: 0.92–0.97), yet the analytic structure survives the B-orth map almost completely. **The CR failure is therefore located in the decoder's response surface, not in the latent geometry.** Its UU block differs most: relative error of the energy-normalised UU block 0.75–0.81, against 0.003–0.014 for B-orth, while UX differs by only 0.07. The decoder logit itself correlates 0.985–0.999 with the true logit. The T-free polynomial surrogate (degree 3, selected on validation loss) predicts η as well as the decoder (r ≥ 0.97) but keeps 0% of the CR analytic passes. Better prediction alone does not repair the curvature structure.
5. **W1-04, global analytic preference** (93 priority metrics; search measure Q01 512×64; reproduced on independent 1024×128 samples).
   - **C families, logit/continuous:** no reproducible global counterexample for C1 and C2. C3 has 11, all far from a permutation (d_SP/√(2k) 0.11–0.51), mostly rowsp / UXrow / Fz recipes.
   - **CR families, logit/continuous:** 63% of the metric × target searches find a reproducible lower loss away from the exact signed permutation. The median distance is 0.047, i.e. a displacement of a few degrees. At distance 0.05 the share drops to 31%, at 0.15 to 15%. The analytic minima are close to, but systematically displaced from, the true axes. The local sweep (15° steps) cannot see this.
   - **Probability channel:** CR counterexamples in 98.5% of searches even at distance 0.15, so Y-P is not a usable target for CR.
   - Only `L03|UX.lq.1` has empirical global support beyond 0.05 on all 8 logit/continuous targets. Its CR searches, however, never ended inside the true basin (weak coverage).
6. **W1-05 hand-off** (`results/next_wave_candidates.csv`; lanes overlap).
   - **A1 (33 metrics):** analytic perfect on all 24 libraries, measure-stable, no global counterexample beyond 0.05. Mostly B09 / B10 joint UX+UU soft-L0 and concentration recipes, SL0.UXUU, POOL / POOLrms, UX.lq.1. All of them pass the decoder on the C families but on 0–1 of the 6 CR libraries. → **Step 2: improve inference of these metrics on CR.**
   - **A2 (211 metric × scope entries: 98 B:C, 99 C:C, 4 B:CR, 10 C:CR):** joint pass on all 6 libraries of one class × family scope, with the analytic arm measure-stable there. On CR: class C has 10 metrics (Fz.A+B+C, Fz.A+K+C, UXrow.a0.5.lq.25, rowsp a0.25–0.75, B08.M03 c0.01/0.03, B08.M05); class B has 4.
   - **B (38):** analytic constant or wrong minimum on some library, or a global counterexample beyond 0.05. This includes the CR-continuous candidates themselves: rowsp / UXrow fail analytically on 12 of the 24 libraries and have counterexamples on C3 / CR3. → Steps 3–5.
   - **C (24):** inferred-only robust passes on C-family scopes: UXrow.a1.*, AXrow.a1.*, B08.M05 / M08, Fz.A+B(+K), CAND. In addition, `L06|B08.M03.c0.01/0.03` is decoder-marginal on all 24 libraries while analytic-perfect on only 8. That makes it the strongest empirical candidate for the Step 6 blind pilot.
   - **D (6 libraries):** CR3 / CR4 / CR5 (class B) supervised ceiling < 0.9. Note, though, that B-orth keeps the analytic passes there too.
   - **E (5 libraries, 42 metrics):** the MASK-ALL derivative estimand of the fixed-bank toys covers only 22% of the points, and many priority metrics change status between MASK-ALL and MASK-COL. → Finite-contrast / reduced-axis targets (Step 5C).

### Deviations from the specification and what was not run

- `metrics_long.csv.gz` is kept as compressed `.npz` loss files per library / measure / seed / channel / mask under `outputs/.../W1/<run>/losses/` (≈ 10⁸ values). `results/pass_summary.csv.gz` holds the per-library evaluations; `outputs/.../W1/analysis/sweep_minima.csv.gz` holds every curve's minimum set.
- Batch D: the frozen escalation rule selected 93 of the 95 priority metrics (all but the two invariant energies), so D covers the full panel.
- Counts at fidelity C / D refer to the 95 / 93-metric panel, not to the 415 registry entries; compare them with the pilot only per metric.
- The polynomial surrogate selected the smallest ridge penalty of the predeclared grid (1e-4) for 11 of 12 toys. The grid was not widened after seeing this.
- Not run: the optional disjoint-context encoder diagnostic (5.4); a separate historical reproduction run of the Lab 03 4096-point / Lab 06 legacy protocols (the loaders and metric code are the historical ones, checked by the decoder-equality and registry-adapter tests); GPU / float32 paths; manifold-gradient refinement in W1-04 (Givens coordinate descent only).
- Lab 03's legacy tolerance (1e-9 (max|L| + 1e-12)) and Lab 06's (1e-9 (max|L| + 1e-300)) give identical flags here; legacy and harmonised columns are both reported.


## How it was run

```powershell
python metric_lab/07_unified_benchmark/validate.py                          # W1-00 gate
python metric_lab/07_unified_benchmark/run_baseline.py --toys all --batch A  # W1-01
python metric_lab/07_unified_benchmark/analyze.py --freeze-priority         # deterministic W1-01 rule -> configs/priority_panel.json
python metric_lab/07_unified_benchmark/run_measures.py --toys all --batch B  # W1-02 (B, C; then --freeze-escalation; D; E)
python metric_lab/07_unified_benchmark/run_bridge.py --toys all             # W1-03
python metric_lab/07_unified_benchmark/run_global_oracle.py --target C1:L:FULL   # W1-04, one call per target (--list)
python metric_lab/07_unified_benchmark/analyze.py --panel primary
python metric_lab/07_unified_benchmark/synthesize.py                        # W1-05
```

`run_all.sh` runs everything in this order (toys in parallel). Every script refuses to overwrite an existing output file (`--resume` skips finished files). Python: `py11` env, CPU, float64.

## Design (what each module does)

| Module | Content |
|---|---|
| `configs/toy_registry.json` | the 12 toys (one designated NP each, repeat 1) and the 5 secondary runs; observation channels; declared X domains (only used to define derivative masks) |
| `wave4_2/inputs.py` | **two interfaces**: `BlindInputs` (Z, X, Y, splits, saved scalers, checkpoint, design metadata — the only object blind code may receive) and `EvalOnly` (T, family, S8/S8_2 references). Blind scorers see a candidate only as `(R, z_mean, z_std)`; labels, R*, G stay in the harness |
| `wave4_2/surfaces.py` | blind response surfaces: frozen decoder (B: class1 − class0 logit; C: output × y_SD + y_mean) and the polynomial surrogate |
| `wave4_2/truth.py`, `bridge.py`, `global_oracle.py` | evaluation-only: analytic η, prior, parameter support, bridges, global analytic search (a unit test checks that no blind module imports them) |
| `wave4_2/measures.py` | Q01–Q05 on TEST subjects, nested across fidelities, complete X rows only; masks FULL / MASK-ALL / MASK-COL |
| `wave4_2/derivatives.py` | AD (reference: η, gradient, Hessian in one pass; Y-P by the exact chain rule), FD / gradient-FD |
| `wave4_2/moments.py` | streamed base-coordinate moments K = E[H_UU ⊗ H_UU], J^(x) = E[h_x h_xᵀ]; exact contraction with J = diag(scale) Qᵀ (squared matrices are never rotated) |
| `wave4_2/metrics.py` | the two registries kept separate: **L03** (153) and **L06** (262) = 415 ids `L03|…`, `L06|…`; fast single-metric L06 evaluator checked against the full library |
| `wave4_2/evaluation.py` | evaluation 1 (pooled Pearson / Spearman over R* + positive angles, exact-matrix dedup, per-curve r) and evaluation 2 (legacy and harmonised tolerance, perfect / marginal, strict = minimum set ⊆ accepted angles, margin m, interior ties) |
