# Metric Lab 03 — 指标随 S9/S9_2 旋转角度的曲线，解析式 vs 神经网络

独立实验：对 `outputs/nn/` 里**所有已保存的 S9 / S9_2 旋转库**，只读取保存好的旋转矩阵 R；能量矩阵**不使用** metric_lab/01 的缓存，全部重新计算（与 `noisy_logit_np` 那一波相同的做法）。结果在 `results/`，大文件在 `outputs/metric_lab/03_s9_metric_curves/`（被忽略）。不修改 S1–S9。

## 方法
- **数据库：** 12 个 test bed（`docs/00_project_flow/02_test_beds.md`）每个指定一个 NP（`toys.py`：二元选择 C1–CR5 用 β=5e-4 repeat01，连续输出 C1L–CR5L 用 T-free 选出的 β），每个都有 S9 和 S9_2 两个旋转库，共 **24 个主库**；另有 6 个附加库（C1/C2/C3/CR4 的 repeat02，CR3 β=5e-5 的 S9 与 S9_2），一共 30 个。S9：R 作用于原始 Z；S9_2：作用于全体被试 z-score 后的 Zz，均值方差取自 S8_2。
- **评价点：** 4096 个点 = 把被试有放回地抽样 × 该模型自己的 X 设计（CR3/CR5 用固定 500 行题库，其余用生成器 `sample_inputs`）。**解析式与神经网络用同一批被试抽样和同一批 X**：解析式的潜变量取该被试的真参数 T，神经网络取其 S5 Z。CR 系列只保留经典二阶导数有定义的内点（amount>0、0<p<1）：CR3、CR5 保留 915/4096 点，CR4 全部保留；解析式与神经网络用同一批点。
- **坐标与目标：** [潜变量原值, X 用 S3 训练集标准化]；目标是 logit。解析式：真实 logit η（`<MODEL>L` 与 `<MODEL>` 用同一个 η）。神经网络：二元选择模型取 decoder 的 class1−class0；`<MODEL>L` 取 decoder 唯一的连续输出，用 S3 训练集 y 的均值和标准差换回 logit 单位（`out·y_std + y_mean`，即 Y-C 通道；对 TEST 被试，换算后的 decoder 输出对真实 logit 的斜率为 0.96–1.00）。
- **同一批评价点：** 每个模型族（如 C1 与 C1L）用同一个随机种子抽被试和 X，且两类 toy 的被试 T 与 X 相同，所以 B 类与 C 类的解析式指标完全相同，差别只来自 NP。
- **能量张量：** C = E[vec(H)vec(H)ᵀ]，H 是对输入的完整 Hessian，两者都用自动微分（解析式对生成公式，神经网络对冻结 decoder）。对每个保存的 R：`Jz = diag(sd)·Qᵀ`（解析式：Q = G = R·R*ᵀ，sd = T 训练集标准差；神经网络：Q = R，sd = 该变体的 Z 标准差），得到 UX、UU 块，再算 152 个指标 + 1 个预注册候选（`CAND.rowsp.75+UXcol.hoy`）。z 融合指标的零分布用同一来源的 200 个 Haar 随机旋转。
- **相关系数：** 每个已保存的旋转是一个样本点（基准 R* 一次 + 所有角度 > 0 的扫描旋转；0° 的扫描项与 R* 重复，已去掉）。报告 pooled Pearson、Spearman，以及"曲线相关"（每个轴子集 7 个角度的 Pearson，对子集取平均）。

## 读法（17 个库时的结果，只含二元选择 NP）
1. **C 系列：** 解析式与神经网络的指标曲线几乎重合（UX/UXcol/POOL 各类 r≥0.97）。
2. **CR 系列：** 全局类（UX.hoy、POOL.hoy、UXrowtot）仍然高度一致（r≈0.92–1.0），但逐行支撑类（rowsp、UXrow）下降到 0.4–0.9，融合指标在 CR4（r=0.39–0.61）上最弱。这与前面"CR 系列需要逐行支撑一族，而这一族神经网络估得最差"的盲旋转结果一致：神经网络与解析式的曲线形状在这一族上并不相同。
3. **UU 块：** C 系列的解析式 logit 对 T 是线性的，UU 块恒为 0，所以所有只依赖 UU 的指标在 C 系列上对解析式**无定义**（表中 NaN，不是 0）；CR 系列上 UU 指标的相关很不稳定（UUdiag.hoy 在 CR3 约 0.25、在 CR4 为 −0.66；UUtri、UUrow 家族中位数为负），神经网络的 UU 结构不能代表解析式的。
4. 这里 NN 是二元选择版 NP（S3 训练的），不是 noisy_logit_np 的回归 NP。

## 限制
- 每个模型只有 1–2 个 NN 训练；S9 只旋转前 d 个轴，k>2 的"角度"是有序 Givens 构造（一种确定构造）。
- CR3、CR5 只用 915 个内点（边界点的 X 导数无经典定义），结论只对内点分布成立。
- 相关系数只衡量曲线形状是否一致，不衡量绝对数值；不同来源的 z 分数各自按本库旋转标准化后画图。

## 角度偏好检验（`angle_preference.py`）
对每个库、每个来源（解析式 / 神经网络）、每个指标、每条轴子集扫描曲线，找出使指标最小（越小越好）的角度（0,15,…,90；相等的角度都算）。**完美通过：** 该库**所有**扫描中最优角度都是 0 或 90（二者都等于 R* 至多差一个带符号置换）。**勉强通过：** 所有扫描中最优角度都在 {0, 15, 75, 90}。曲线恒为常数的指标（例如解析式 C 系列的 UU 块）一律不算通过。结果：`results/angle_pref_{long,db_summary,metric_summary}.csv`。

## Z → T 线性回归（`z_to_t_regression.py`，结果 `results/z_to_t_regression*.csv`）
对本分析纳入的全部 NP（11 个二元选择 NP、10 个回归 NP）：在 TRAIN 被试上做带截距 OLS，用从未参与拟合的 TEST 被试报告 R²（各参数）；另加二次岭回归（所有平方与交叉项）作非线性参照。T 只用于这个诊断。线性 R² 的各参数均值 / 最小值：二元 C1/C2/C3 0.944–0.955 / 0.92–0.946；二元 CR3 0.759 / 0.70；二元 CR4 0.72 / 0.65；二元 CR5 0.78 / 0.72；回归 C1/C2/C3 0.990–0.996 / 0.98–0.996；回归 CR3 0.946 / 0.936；回归 CR4 nn1 0.860 / 0.810，**回归 CR4 r2 仅 0.392 / 0.131**。二次项只带来 0.001–0.03 的提升。
